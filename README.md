# x11.zig

A modern Zig-native X11 client library.

## Status

Early development.

## Goals

- Provide a modern, Zig-native interface to X11.
- Provide direct access to the X11 protocol without requiring Xlib or XCB.
- Offer useful abstractions and quality-of-life improvements without hiding X11 concepts and semantics.
